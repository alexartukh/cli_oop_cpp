SHRMS - Simple HRMS - простая система управления персоналом (расчета зарплаты группы сотрудников)

Глобально сущностей всего 2 вида : персоны и акутивности.
Но персоны имеют разновидности и активности имеют разновидности. Поэтому реально классов больше.

Каждый сотрудник имеет список активностей.
На основании этого списка активностей вычисляется его зарплата.
Сырые данные хранятся в БД.
Суть программы - создание отчета по данным из БД.
В процессе создания отчета сырые данные из БД превращаются в коллекцию объектов. По ним вычисляется зарплата.

Каждый сотрудник принадлежит к какой-то круппе.
Каждая активность проинадлеждит к какому-то проекту.

**Классы для персон**

Person - абстрактный сотрудник. Имеет список активностей.
- PersonWorker - обычный работяга. Получает  
- PersonManager - менеджер, который может иметь работяг в подчинении. Получает бонус в зависимости от количества работяг.

**Классы для активнеостей**

Activity - абстрактная активность сотрудника
- ActivityPaid - оплачиваемая активность
-- ActivityOvertime - подвид оплачиваемой активности, которая удваивает количество потрачиваемых на нее часов.
- ActivityNotPaid - неоплачиваемая активность. За нее положено 0 денег независимо от количества часов, потраченных на нее.

Отчета в программе 2
- подсчет денег по группам сотрудников
- подсчет денег по проектам
Фактически номер группы или номер проекта выступает фильтром, по которому выбираются данные.
