HRMS

Каждый сотрудник имеет набор активностей за отчетный период времени.
На основании этого набора активностей вычисляется его зарплата.


**Классы для людей**

Person - абстрактный сотрудник
- Worker - обычный работяга
-- Coach - подвид обычного работяги, который может инструктировать другого работягу 

- Manager - менеджер, который может иметь работяг в подчинении

**Классы для активнеостей**

Activity - абстрактная активность сотрудника
- PaidActivity - оплачиваемая активность
-- PaidVacation - оплачиваемый отпуск
-- BusinessTrip - оплачиваемая коммандировка

- NotPaidActivity - неоплачиваемая активность
-- NotPaidVacation - неоплачиваемый отпуск

**Служебные классы**

Profile - класс профиля, который есть у любого человека. Вынесен в отдельную сущность для удобства расширения.
